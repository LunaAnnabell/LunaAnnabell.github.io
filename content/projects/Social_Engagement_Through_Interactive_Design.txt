Describtion of project:

The final product is a T-shaped prototype Android application built in Android Studio using Java and XML, structured via an open-strict layered architecture. It features dynamic character selection, category filtering, a detailed event timeline, and a functional calendar view. Evaluated through Nielsen's usability heuristics, the project concludes that blending gamified navigation paths (inspired by Duolingo and Candy Crush) with localized event discovery effectively bridges the gap for newcomers trying to integrate into a new city
