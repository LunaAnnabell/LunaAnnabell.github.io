Describtion of project:

The project investigates the potential and limitations of automating manual appointment coordination through Agentic Artificial Intelligence (AAI). Moving past a basic first rendition focused purely on Streamlit/MySQL CRUD digitisation, the second prototype introduces a conversational user interface (CUI) powered by an LLM (OpenAI) integrated via a Flask backend. The system evaluates user input, calendar availability (Google Calendar API), and local weather data (DMI) to autonomously recommend and schedule cleaning appointments.

Solution and conclusion:

The project implemented a hybrid UI combining conversational AI flexibility with structured visual widgets (weather, addresses, profiles, and calendars) to minimize user cognitive load. Evaluated through expert-based Heuristic Evaluations using Nielsen's heuristics, the project concluded that while AAI drastically reduces administrative burdens, it introduces challenges regarding user trust, system transparency, and conversational predictability, emphasizing that hybrid interfaces are vital to keep users in control
