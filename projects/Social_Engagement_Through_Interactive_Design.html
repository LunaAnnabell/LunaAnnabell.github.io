Interaction Design / Human-Computer Interaction (HCI)

Social Engagement and Design

An iterative approach to event discovery

Role: Participatory Design Facilitator, UX/UI Designer, and Usability Evaluator

Context: 8th semester project at Aalborg University

Timeframe: Spring 2025

Description: An iterative interaction-design project focused on helping newcomers discover events and integrate into a new city.

Solution and Conclusion

Conclusion: The final product is a T-shaped prototype Android application built in Android Studio using Java and XML, structured via an open-strict layered architecture. Evaluated through Nielsen's usability heuristics, the project concludes that combining gamified navigation with localized event discovery can help newcomers integrate into a new city.
